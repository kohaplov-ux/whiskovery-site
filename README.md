# Whiskovery site

Static site hosted on GitHub Pages from `main` (repository root).

- `/`: homepage
- `/beta/`: Korean Android Closed Beta tester guide
- `/privacy/`: privacy information
- `/support/`: support and account deletion information

The beta guide shares the existing site fonts/styles and has scoped styles in
`assets/beta.css`. The source for its social preview is `assets/beta-share.svg`;
`assets/beta-share.jpg` is the 1200×630 raster preview used by sharing services.
No analytics, forms or tester contact lists are embedded in the guide.

The guide and social preview use the official Whiskovery logo from
`assets/whiskovery-icon.svg`. Preserve its original colors and proportions.
